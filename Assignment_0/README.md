## Assignment 0 Overview

Assignment 0 is a warm‑up designed to refresh mathematical and programming skills.  
It includes problems on:

- Recursive sequences and fixed‑point stability  
- Chebyshev polynomials and 2D surface plots  
- IEEE floating‑point arithmetic and error bounds  
- Matrix condition numbers and stability properties  
- Gamma function interpolation  
- Numerical differentiation (Taylor expansions, finite differences)

Each problem has a dedicated Python script in `Assignment_0/src/`.
