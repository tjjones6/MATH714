# Math/CS 714 — Methods of Computational Mathematics I  
University of Wisconsin–Madison  
Fall 2026

This repository contains my coursework, code, notes, and project materials for **Math/CS 714: Methods of Computational Mathematics I**. The course focuses on the development and analysis of numerical methods for solving partial differential equations (PDEs), with an emphasis on finite difference methods and related computational techniques.

---

## Course Overview

Math/CS 714 (followed by Math/CS 715) covers numerical methods for:

- Elliptic PDEs  
- Parabolic PDEs  
- Hyperbolic PDEs  

The course emphasizes:

- Finite difference methods (primary focus)  
- Finite volume and spectral methods (secondary coverage)  
- Stability, consistency, and convergence analysis  
- Numerical solution of large linear systems  
- Implementation of PDE solvers in scientific computing environments  

Assignments include both theoretical analysis and practical programming components.

---


Each assignment directory may contain:

- `src/` — Python or MATLAB code  
- `report/` — LaTeX writeup  
- `figures/` — plots generated by code  
- `results/` — numerical output  
- `notes/` — derivations or scratch work

## Assignment Information

The course includes:

- **Introductory Assignment 0** (ungraded)  
- **Five graded homework assignments**  
  - Homework 1 due September 26  
  - Remaining assignments due every 2–3 weeks  
- **Final Project** (40% of grade)  
  - Group project (2–3 students; ≥4 with permission)  
  - Includes code, report, and presentation  
  - Must apply concepts from the course  
  - Code must be reproducible and well‑documented  

Grading breakdown:

- Homework: **55%**  
- Group activities: **5%**  
- Final project: **40%**
