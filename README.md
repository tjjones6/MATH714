# Math 714 — Computational Mathematics I
University of Wisconsin–Madison  
Fall 2026

This repository contains my coursework, notes, and computational experiments for **Math 714: Computational Mathematics I**, following the structure and topics from the course website:  
https://web.math.wisc.edu/math714/archive/fall2025/

The course emphasizes:
- Floating‑point arithmetic  
- Numerical stability  
- Conditioning and error analysis  
- Polynomial interpolation  
- Numerical differentiation  
- Numerical integration  
- Iterative methods  
- Linear algebraic systems  
- Nonlinear solvers  
- Scientific computing workflows in Python

All assignments are organized into subdirectories with source code, figures, notes, and results.
